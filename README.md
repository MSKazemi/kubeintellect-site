# kubeintellect.com

This repository is the **published build** of [kubeintellect.com](https://kubeintellect.com) —
the website of [KubeIntellect](https://github.com/MSKazemi/kubeintellect), the open-source,
human-governed AI SRE for Kubernetes. GitHub Pages serves this branch as-is.

The files here are generated (a static Next.js export) and replaced on every deploy, so please
don't send changes against them. For the product itself, see
[MSKazemi/kubeintellect](https://github.com/MSKazemi/kubeintellect); to get in touch, see
[kubeintellect.com/contact](https://kubeintellect.com/contact).

Peer-reviewed: *KubeIntellect*, Journal of Grid Computing (Springer, 2026),
[DOI 10.1007/s10723-026-09837-6](https://doi.org/10.1007/s10723-026-09837-6).
